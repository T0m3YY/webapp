# Experimental Web Application

This experimental web application demonstrates dynamic features like theme toggling, GitHub API integration, and category-based content organization. 

## Features
- Dark/Light mode toggle with local storage.
- Automatic display of the latest GitHub commits and repository data.
- Responsive design for seamless use on different devices.
- Carousel-based content browsing for films and series.

## Purpose
Originally developed as a school project, this web app serves as a showcase of front-end development skills, including:
- API integration
- Responsive web design
- Dynamic DOM manipulation

## Future Plans
- Add trending and recommended content sections.
- Improve accessibility and cross-device compatibility.
- Experiment with additional API integrations for movie and series data.
